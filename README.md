# project-course-work
## Техническое задание для проекта «**Студенческий хаб**»

### 1. Краткое описание приложения

Веб-приложение для помощи студентам в организации учебного процесса. На одной странице объединены два функциональных блока:
личные заметки и список дедлайнов. Данные хранятся в сервисах и отображаются на единой странице.

Заметки - как возможность записать важные вещи по учёбе. Дедлайны - чтобы не держать все сроки сдачи учебных работ в голове.

### 2. Основная функциональность

*Главная страница:*
- Отображает список заметок
- Отображает список дедлайнов

*Для заметок:*
- Просмотр всех созданных заметок
- Добавление новой заметки (заголовок + текст)
- Удаление заметки

*Для дедлайнов:*
- Просмотр всех дедлайнов
- Добавление нового дедлайна (название задачи + дата)
- Удаление дедлайна

Два независимых сервиса: один отвечает за заметки, второй - за дедлайны. У каждого своя база данных. Сервисы будут общаться через HTTP-запросы. Один сервис отправляет запрос другому и получает ответ с данными.
